# CEN4721-Budgeting-Website
Our teams budgeting website. 

Informal setup section: Run `npm i` inside both the frontend and the backend. For the backend, install mongodb locally on your machine and then use the mongo shell to create a db for this project. Copy over the contents from `env_template.txt` into a new `.env` file inside the backend folder and change `DB_NAME` to the name of your DB you made in the mongo shell.

To run the backend, cd into it and run 'npm run dev' and should output it running correctly.
To run the frontend, cd into it and run 'npm start' and the website should open up in your web browser.
